# Uploading & Downloading Image/Video on Google Drive – React Native Demo

A React Native demo project that shows how to **upload and download image & video files** to/from Google Drive API.  
Built to demonstrate how to integrate mobile file-storage workflows in real apps (Android & iOS).

---

## 🎯 What this project does

- Let users pick images or videos from their device (gallery/camera).  
- Upload these files to Google Drive via React Native mobile app (using appropriate API/library).  
- Download files from Google Drive and display in the app (image/video playback).  
- Designed as a reference project for mobile app developers working on media content flows.
